CXRBrownfield turns a hand-drawn site sketch into an editable 3D environment. A Flask server on port 5002 holds every environment and building as a JSON record under server/data, filed by kind into user-authored and generated folders. You upload an image, and a Gemini call converts it into a layout carrying a lot boundary, building footprints, paths, and fences. The Unity client pulls those records over HTTP and renders them onto a terrain sized to the parcel, with everything outside the boundary polygon masked to water. Buildings are assembled from tiles instead of solid blocks. Each cell owns its own face materials, so a wall can be brick on one side and glass on the other.

Editing runs in play mode through a right-hand rail. Standard move, rotate, and scale gizmos handle placement, with box-select for grabbing scattered props and a copy-paste clipboard that works across environments. Double-clicking a building opens a tile editor where you paint materials, stack doors and windows onto faces, and reshape the footprint. A separate terrain rail draws path ribbons, repeats fence panels along a drawn centerline, scatters trees with a density brush, and stamps ground surfaces into the splatmap. Several environments can be loaded at once. One stays active and editable while the rest sit as dimmed backdrops, and a persistent lock flag makes a digital twin read-only so new design work has to branch off a copy. Flipping the Live toggle publishes the loaded set to a shared pointer file on the server. A separate VR viewer scene polls that pointer roughly every second and a half, then rebuilds whatever changed, giving a headset a read-only mirror of the desktop host.
